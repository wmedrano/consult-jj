#+TITLE: Consult JJ

JJ integration for Emacs.

[[./resources/demo.gif]]

* Requirements

- Emacs 30+
- [[https://github.com/martinvonz/jj][Jujutsu (jj)]] CLI installed and accessible in your ~PATH~
- ~vertico~ and ~markdown-mode~ (required by ~consult-jj-describe~)

* Installation

** package-vc

#+begin_src emacs-lisp
(use-package consult-jj
  :vc (:url "https://github.com/wmedrano/consult-jj.git"))
#+end_src

** straight.el

#+begin_src emacs-lisp
(use-package consult-jj
  :straight (:host github :repo "wmedrano/consult-jj"))
#+end_src

** Elpaca

#+begin_src emacs-lisp
(use-package consult-jj
  :ensure (:host github :repo "wmedrano/consult-jj"))
#+end_src

** MELPA (Coming Soon)

Once ~consult-jj~ is available on MELPA, you will be able to install it via ~M-x

#+begin_src emacs-lisp
(use-package consult-jj
  :ensure t)
#+end_src

* Functions

* Generic

| Functions                  | Description                                                          |
|----------------------------+----------------------------------------------------------------------|
| ~consult-jj-root~          | Get the root directory or signal an error if not in a JJ repository. |
| ~consult-jj-read-revision~ | Prompt for a revision and return its change id.                      |
| ~consult-jj-run-command~   | (Non interactive) Run a jj subcommand at the root of the repository. |

** JJ Working Copy

| Functions             | Description                                                      |
|-----------------------+------------------------------------------------------------------|
| ~consult-jj-new~      | Create a new change on top of a revision.                        |
| ~consult-jj-edit~     | Move the working copy to a revision.                             |
| ~consult-jj-git-push~ | Push a revision to the remote with ~jj git push -r~.             |

** JJ Diff

| Functions              | Description                                                                                                                                                                 |
|------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ~consult-jj-diff-at~   | Show the diff of a revision in a new ~*jj-diff*~ buffer.                                                                                                                    |
| ~consult-jj-diff-from~ | Show the diff from a revision to the working copy in a new ~*jj-diff*~ buffer; with a prefix argument, also prompt for a second revision and show the diff between the two. |

** JJ Describe

| Functions             | Description                                                     |
|-----------------------+-----------------------------------------------------------------|
| ~consult-jj-describe~ | Edit the description of a revision in a ~*jj-describe*~ buffer. |

Editing a change description opens a ~consult-jj-describe-mode~ buffer
containing the current description followed by comment lines prefixed with
~JJ:~.  Those comment lines are stripped before the description is saved.

| Key       | Function                     | Description                                                                         |
|-----------+------------------------------+-------------------------------------------------------------------------------------|
| ~C-c C-c~ | ~consult-jj-describe-accept~ | Set the buffer's contents as the description of the revision, then kill the buffer. |
| ~C-c C-k~ | ~consult-jj-describe-reject~ | Kill the buffer without saving the description.                                     |
| ~C-c C-d~ | ~consult-jj-describe-diff~   | Show the diff of the change being described.                                        |

* Configuration

| Variable                 | Default                                                                     | Description                           |
|--------------------------+-----------------------------------------------------------------------------+---------------------------------------|
| ~consult-jj-executable~  | ~"jj"~                                                                      | Path to the jj executable.            |
| ~consult-jj-global-args~ | ~("--config" "ui.progress-indicator=false" "--color" "never" "--no-pager")~ | Args prepended to every ~jj~ command. |

Example:

#+begin_src emacs-lisp
(setq consult-jj-executable "/path/to/jj")
#+end_src

** Faces

The ~jj log~ output is fontified using the following faces.

| Face                             | Inherits                  | Description                                    |
|----------------------------------+---------------------------+------------------------------------------------|
| ~consult-jj-bookmark-face~       | ~font-lock-type-face~     | Bookmarks in the jj log.                       |
| ~consult-jj-change-id-face~      | ~font-lock-constant-face~ | Change ids in the jj log.                      |
| ~consult-jj-selected-face~       | ~highlight~               | The currently selected revision in the jj log. |
| ~consult-jj-graph-face~          | ~font-lock-keyword-face~  | Graph line characters in the jj log.           |
| ~consult-jj-email-face~          | ~font-lock-string-face~   | Email addresses in the jj log.                 |
| ~consult-jj-timestamp-face~      | ~font-lock-type-face~     | Timestamps in the jj log.                      |
| ~consult-jj-commit-id-face~      | ~font-lock-comment-face~  | Commit ids in the jj log.                      |
| ~consult-jj-no-description-face~ | ~font-lock-comment-face~  | "(no description set)" in the jj log.          |

** Writing Your Own Commands

You can build your own JJ commands by using ~consult-jj-read-revision~ to read a
revision, and, optionally, ~consult-jj-run-command~ to run a command and output
its result to the minibuffer.

Here is an example that implements ~jj git push~:

~consult-jj-read-revision~ (which prompts with the ~jj log~ shown in a side
window) is optional — you can use any prompt mechanism and any arguments you
like.  For instance, to push to a specific remote:

#+begin_src emacs-lisp
(defun my-consult-jj-git-push-to-remote (remote rev)
  "Push change REV to REMOTE."
  (interactive (list
                (read-string "Remote: " "origin")              ;; Argument REMOTE
                (consult-jj-read-revision "jj git push" "@"))) ;; Argument REV
  (consult-jj-run-command `("git" "push" "--remote" ,remote "-r" ,rev)))
#+end_src
